# Rules
1. 文化语境视角 (Cultural Lens): 结合上述注入的字典知识（如有）和你的社会学认知，评估焦点区域内的文本。如果文本利用黑话进行隐蔽攻击、使用去人化叙事模板，或宣扬结构性偏见，判定为有害 (`hateful: 1`)。
2. 视野锁死 (Attention Lock - CRITICAL): 你的核心剖析区域**仅限**于 `<focus>` 和 `</focus>` 标签内部。**严禁**越权惩罚标签外部的严重违规行为或恶意词汇。标签外的文本仅用于补全缺失的信息。
3. 目标补全 (Target Resolution): 优先从 `<focus>` 内部提取 `target`。
   - 只有当焦点文本内部明显缺失主语时，你才被允许利用标签外部的上下文来补全目标；如果 `<focus>` 内已经有明确 target，严禁被外部上下文覆盖。
   - 如果下面给出了 `Target hint`，它也只是软提示，只能在焦点片段残缺时参考，不能覆盖 `<focus>` 内已明确出现的 target。
   - 如果焦点内无明确目标，输出 `"IMPLICIT_TARGET"`。
4. 论据提取 (Argument Extraction): `argument` 必须是 `<focus>` **内部**的精确子串，并尽量选择最短、最核心、最能成立的黑话/歧视/文化攻击片段。
5. 多重论据与目标拆分 (Multi-Target/Argument Extraction - CRITICAL): 焦点内如果出现多个独立攻击、评价或谓词，必须拆成多个对象；不要因为它们靠得近，或被“和/以及/逗号”等连接，就合并成一个长 argument。
6. 非空论据 (Non-empty Argument - CRITICAL): `argument` 绝不能是空字符串。即使判定为无害 (`hateful: 0`)，也必须选择 `<focus>` 内部一个最短、最能支撑该无害判断的精确子串。
7. 输出序列 (Output Sequence): 你必须输出一个 JSON Array。内部对象顺序：`rationale`, `target`, `argument`, `hateful`。`rationale` 必须简明扼要（少于 50 字），剖析黑话的潜台词或语境反转，且必须保持单行，禁止在字符串内部换行。
